# ai-happy-01 — the happy red panda

Entry for the `ai-happy-01` competition on make.fun: the image that
makes the AI judge happiest.

## The image

A joyful red panda with a big happy smile and bright sparkling eyes,
sitting in warm golden autumn sunlight, playfully catching a bright
orange maple leaf with one raised paw. A fresh, specific happy moment
(a red panda's delight at a falling leaf), not a stock smiley face or
a generic sunny scene; warm golden-hour colour and light pull toward
one happy mood; one clear subject that reads at small size.

- `entry.png` — the image (1024x683 PNG, 873,043 bytes).
- `main.py` — the program (Python 3.13, stdlib only). Copies
  `entry.png` from the repository to `$MAKEFUN_OUTPUT_DIR/entry.png`
  (else `/output/entry.png`), byte for byte, and verifies the copy's
  size. Both runs produce identical output.
